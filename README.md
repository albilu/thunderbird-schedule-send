# thunderbird-scheduled-send

Thunderbird extension to Schedule email sending.

## Features

- At specific date and time
- Send in x Minutes
- Recurring: x Min, dayly, monthly, yearly
- Between 01:00 and 05:00
- Only: x y z week days
- Presets: In 5/10/30 minutes

## Hard Requirements

- Schedule Send Button near the thunderbird default Send Button
- Dropdown popup
- Default thunderbird color theme
- i18n: french and english

## Brainstorming

Thunderbird lack a built in Schedule sender, there is an attempt to solve this pain point with https://github.com/Extended-Thunder/send-later but it is not well polished. Goal of this project is to implement a proper solution with a smooth integration with Thunderbird
